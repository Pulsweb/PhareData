# Ressources

Éléments réutilisables d'un épisode à l'autre : jeux de données légers, visuels de
la chaîne, listes de sources et documents de référence.

Les fichiers volumineux (rushes, exports vidéo, jeux de données massifs) ne doivent
pas être versionnés ici : hébergez-les ailleurs et référencez le lien.
