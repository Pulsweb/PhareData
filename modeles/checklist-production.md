# Checklist de production — [Titre de l'épisode]

## 1. Préparation

- [ ] Sujet validé et angle défini
- [ ] Sources vérifiées et jeux de données rassemblés
- [ ] Script rédigé à partir de `modeles/script-episode.md`
- [ ] Support de présentation préparé dans `presentations/`
- [ ] Démonstration ou code testé de bout en bout

## 2. Enregistrement

- [ ] Matériel testé (micro, caméra, éclairage)
- [ ] Environnement de capture nettoyé (bureau, notifications désactivées)
- [ ] Prise de son et image de référence validée
- [ ] Enregistrement des séquences principales
- [ ] Sauvegarde des rushes hors du dépôt

## 3. Montage

- [ ] Dérushage et montage de la trame
- [ ] Habillage, titres et illustrations
- [ ] Sous-titres relus
- [ ] Miniature créée
- [ ] Relecture complète de l'export final

## 4. Publication

- [ ] Titre, description et tags renseignés
- [ ] Chapitres ajoutés
- [ ] Liens et sources mentionnés dans la description
- [ ] Date et heure de publication programmées
- [ ] Annonce préparée pour les réseaux sociaux

## 5. Après publication

- [ ] Réponses aux premiers commentaires
- [ ] Statistiques relevées après 7 jours
- [ ] Retours consignés pour les prochains épisodes
