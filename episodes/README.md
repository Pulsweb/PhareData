# Épisodes

Un sous-dossier par épisode, nommé `EP000-titre-court`, regroupant :

- `script.md` — le script de l'épisode, copié depuis `modeles/script-episode.md`
- `checklist.md` — le suivi de production, copié depuis `modeles/checklist-publication.md`
- `notes.md` — les notes de préparation et les sources (optionnel)

Le code et les supports visuels correspondants sont placés respectivement dans
`scripts/` et `presentations/`, sous le même nom d'épisode.
